# Проверка WebDAV

Запустите `python webdav.py` из этого каталога. Нужны Python 3, пакет `playwright` и Chromium. Сценарий использует системный `chromium` или браузер, установленный командой `playwright install chromium`.

Сценарий запускает локальный HTTP-сервер с обработчиками WebDAV и загружает установочный JavaScript плагина в Chromium с тестовой реализацией API Obsidian. Проверяются направления обмена, политики удаления и конфликтов, условные запросы, повторные запуски, перенос настроек 0.1.0 и события автосинхронизации.

Проверки облачных движков запускаются командой `node --test cloud.test.cjs` в этом каталоге. Используются тестовые ответы Google Drive v3 и Яндекс Диска REST API. Сценарии проходят через собранный плагин и проверяют предпросмотр, создание, скачивание, перезапись, конфликты, корзину, смену аккаунта и обновление токена Google.

Для пересборки установите зависимости командой `npm ci` в корне репозитория, затем выполните `npm ci && npm run build` в `plugins/vault-folder-sync/`.
