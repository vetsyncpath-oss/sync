# Как плагины Obsidian получают доступ к данным

Сравнение основано на исходном коде указанных ревизий. Режимы других плагинов описаны по их реализации. В этом тестировании экземпляры этих плагинов к аккаунтам не подключались.

| Источник | Что делает другой плагин | Как подключается Vault Folder Sync 0.4.0 |
| --- | --- | --- |
| Google Drive | **Google Drive Sync** отправляет авторизованные запросы Drive v3. При собственных client ID/secret он обменивает refresh token на access token у Google. Для поиска файлов хранилища код использует пользовательское свойство vault. [Авторизация](https://github.com/richardx366/Obsidian-Google-Drive/blob/1922dd0615a517f399594188648f239a23caf1bd/helpers/requests.ts#L116) · [Поиск файлов](https://github.com/richardx366/Obsidian-Google-Drive/blob/1922dd0615a517f399594188648f239a23caf1bd/helpers/drive.ts#L143) | Для аккаунта доступны desktop OAuth с PKCE и ввод токена. Для публичной папки используются Drive API key, ID папки и, если он есть, resource key из ссылки. Обход начинается с выбранной папки. На сервер ничего не записывается. |
| Яндекс Диск | **Yandex Disk Sync** получает и обновляет токен Яндекс ID и передаёт его в API Диска. Для чтения и записи использует методы resources/download и resources/upload. [OAuth](https://github.com/nikolay-eltsov/obsidian-yadisk-sync/blob/27993072571dbbbf22f03eccf02aea5827570e34/src/yandex-client.ts#L139) · [Передача файлов](https://github.com/nikolay-eltsov/obsidian-yadisk-sync/blob/27993072571dbbbf22f03eccf02aea5827570e34/src/yandex-client.ts#L549) | Для личного Диска требуется OAuth-токен. Для опубликованной папки ссылка передаётся как public_key в public/resources. Файлы скачиваются через public/resources/download без токена. Закрытая ссылка или неполный ответ останавливает сравнение. |
| Git | **Obsidian Git** использует системный Git через simple-git на компьютере и реализует clone, pull, commit и push. На мобильном клиенте используется isomorphic-git с отдельными ограничениями. [Настольный backend](https://github.com/Vinzent03/obsidian-git/blob/c11fe1ff7b58a1ee49fbd6176d20dd3cc74cd95e/src/gitManager/simpleGit.ts#L853) · [Мобильный backend](https://github.com/Vinzent03/obsidian-git/blob/c11fe1ff7b58a1ee49fbd6176d20dd3cc74cd95e/src/gitManager/isomorphicGit.ts#L509) | Vault Folder Sync получает снимок выбранной ветки, тега или коммита. Для GitHub использует REST API и читает объекты по SHA. Для других HTTPS-серверов настольный клиент запускает системный Git во временном репозитории. В хранилище Obsidian попадают выбранные файлы. |

**Практический выбор.** Для получения чужой коллекции заметок достаточно публичной ссылки. В Google Drive дополнительно нужен API key проекта с включённым Drive API. Для отправки правок владельцу папки в облаке выберите обычную пару с авторизацией. Для ведения Git-истории, коммитов и push в самом хранилище подходит рабочий процесс Obsidian Git.
