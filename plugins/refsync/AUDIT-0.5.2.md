# Разбор аудита Sync Studio 0.5.1

## Почему большое зеркало долго показывает «Сравнение»

В 0.5.1 локальный обход на каждой стороне запрашивал метаданные, читал тело каждого подходящего файла и вычислял SHA-256. Для удалённого источника иногда переиспользовался целый снимок по ревизии. У запуска был общий дедлайн 300 секунд. При каждом запуске по расписанию обход мог начинаться заново. Отдельно при проверке массовых удалений из облачного источника список файлов одного каталога повторно перебирался для каждого удаляемого пути. Без трассы исходного хранилища нельзя определить, какой из этих факторов наблюдал пользователь.

В 0.5.2 видны счётчики обхода, чтений и повторного использования. Индекс версий файлов на устройстве переживает перезапуск. Доступная SHA-256 облачного файла может использоваться уже при первом сравнении. Проверка массового удаления строит индекс каталога один раз. При недоступном чтении остаются ограниченные тайм-ауты и повторы. Полная проверка через настройки читает содержимое и оставляет статистику в журнале. Семантическое сравнение JSON настроек по-прежнему требует доступа к их содержимому.

| Сценарий | Результат проверки |
| --- | --- |
| 3 000 файлов источника и 3 000 других файлов цели, полное зеркало | 6 000 запланированных операций. Чтения содержимого при первом сравнении — 6 000, при втором — 0, после изменения одного файла той же длины — 1, при полной диагностике — 6 000. Это тест движка с инструментированным провайдером. |
| Настольный Obsidian, тестовое хранилище с кириллицей, 256 файлов в каждой папке | Первый обход прочитал 512 тел, повторный использовал метаданные всех 512. Тихая доставка создала 256 файлов и удалила 256. Проверены результат на диске и поиск удалённого пути в журнале. |
| Зависшее чтение и истечение пяти минут | Тест с управляемыми часами пропускает десять минут успешного запуска. Отдельный тест с незавершающимся чтением возвращает ошибку и относительный путь. |

## Результаты по замечаниям аудита

| Пункт | Что изменилось или осталось |
| --- | --- |
| C, H | Снят общий пятиминутный предел, сохранены пределы отдельных операций. Базовые линии записываются атомарно в IndexedDB. Предыдущая версия в localStorage доступна до переноса. Свободное место на устройстве по-прежнему требуется для пакета и отката. |
| B | Стартовая сверка только регистрирует расхождения. Проверено сохранение локальной правки после перезапуска. |
| G, ZZ | Очистка сохраняет последнюю доступную транзакцию для отката и незавершённые транзакции. Пакетный режим проверяет неизменённые файлы без сохранения их лишних копий. Резервные копии и корзина по-прежнему хранятся отдельно. |
| W, A, L | Политики выбора цели и более новой версии учитываются для изменённых с обеих сторон горячих настроек. Переход к профилю настроек требует явного выбора категории кода. Некорректный JSON отмечается в сравнении; пакетная доставка останавливается, а в режиме изменений обрабатываются остальные пути. |
| U, O | После пользовательского отката профиль выключается. Команда получает провайдер назначения из транзакции и может восстановить локальный файл при недоступном облачном источнике. |
| D, X | Издатель проверяет уже видимые проблемные пути перед записью, причина и путь попадают в журнал. Для контента сравнивается также существующий манифест с состоянием назначения. Изменение во время выгрузки всё ещё может потребовать отката. Обновление устаревшего манифеста профиля настроек без других операций остаётся отдельным случаем. |
| V | Переименование профиля при сохранении допускает завершение текущей доставки. Изменение состава или назначения, выключение профиля и пауза по-прежнему прерывают доставку. |
| F, E | Повреждённая запись локального восстановления может блокировать запуск. Оставшийся облачный маркер незавершённой публикации может блокировать публикацию и подписку. Автоматического сброса этих записей в версии 0.5.2 нет. Для разбора важны код ошибки и копия журнала до ручных изменений. |
| OV | Объединение локальных полей элементов массива по wildcard по-прежнему зависит от позиции элемента. Для объектов с меняющимся порядком массива нужен отдельный механизм сопоставления. |
| Прочие замечания | Исправлены повтор после ошибки чтения корня облака, проверка недействующего варианта доступа и название команды переключения режима. Ограничения Git по памяти, мобильная системная корзина, точность времени отдельных облаков, пересечение разных профилей и другие низкоприоритетные пункты не проверялись на реальных устройствах и аккаунтах в этом разборе. |
