# 0.2.0

- Отдельная постоянная вкладка подключений, редактирование из профиля и списка.
- Формы для каждого сервиса; Яндекс и GitHub больше не показывают Google OAuth.
- Авторизация Google оставляет мастер открытым; доступны проверка папки, сохранение и создание профиля.
- Автосохранение полей не перерисовывает экран и сохраняет порядок записей.
- Проверка нового токена не заменяет сохранённый токен до нажатия «Сохранить».
- Браузер папок Google Drive и Яндекс Диска с переходом назад и к корню.
- Исправлен путь корня Яндекса `disk:/`; поддержаны безопасные перенаправления при скачивании.
- Обход учитывает scope/исключения до проверки коллизий; ошибки показывают пути и позволяют явно исключить их.
- Google Docs/shortcuts пропускаются с предупреждением и не превращаются в удаления.
- Локальная установка файла использует атомарную замену, а не API перемещения, которое может отвергать существующий файл.
- Ошибки доступны на экране и в истории; план не закрывается при неудачном выполнении, доступна перепроверка.
- Добавлены DOM-интеграционные тесты полного цикла и транспортные регрессии.
