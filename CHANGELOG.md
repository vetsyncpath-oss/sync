# 0.3.0 — аудит ядра и источников

- Общая проверка коллизий между сторонами, включая файл/папку, пустые папки, регистр и Unicode; защита служебных путей от вариантов регистра.
- Scope применяется к внешним папкам до обхода; GitHub применяет исключения до проверки submodules/symlinks.
- Drive: свежее разрешение пути перед чтением/записью, проверка перемещённых родителей, MIME, resumable upload >5 MiB с подтверждёнными диапазонами и восстановлением после потерянного ответа.
- Опциональный выбор новейшего одноимённого файла Drive при получении по подходу Sync Engine; дубли папок остаются ошибкой.
- Явный режим зеркала для одного направления. Старые профили сохраняют отслеживаемые удаления.
- Копирование до удалений, отмена устаревшего плана при изменении mtime, защита pending-операции от повторного запуска и исключения из scope.
- Задержка повторных автоматических запусков учитывает ошибки исполнения; Яндекс HTTP 202 upload ожидает подтверждения hash.
- AUDIT.md: проверка готовности источников, сравнение с Sync Engine и FreeFileSync, ограничения и приоритеты.

# 0.2.1

- Профили редактируются через явные кнопки «Изменить», «Сохранить», «Отмена» сверху и в закреплённой нижней панели.
- Правки остаются в отдельном черновике при переключении вкладок и не влияют на синхронизацию до сохранения.
- Проверка настроек перед сохранением; при ошибке записи прежний профиль сохраняется, черновик доступен для повторной попытки.
- Сохранение отменяет устаревший ожидающий план. Изменённый другим действием профиль защищён от перезаписи устаревшим черновиком.
- Добавлены интеграционные тесты сохранения/отмены и ошибок записи.

# 0.2.0

- Отдельная постоянная вкладка подключений, редактирование из профиля и списка.
- Формы для каждого сервиса; Яндекс и GitHub больше не показывают Google OAuth.
- Авторизация Google оставляет мастер открытым; доступны проверка папки, сохранение и создание профиля.
- Автосохранение полей не перерисовывает экран и сохраняет порядок записей.
- Проверка нового токена не заменяет сохранённый токен до нажатия «Сохранить».
- Браузер папок Google Drive и Яндекс Диска с переходом назад и к корню.
- Исправлен путь корня Яндекса `disk:/`; поддержаны безопасные перенаправления при скачивании.
- Обход учитывает scope/исключения до проверки коллизий; ошибки показывают пути и позволяют явно исключить их.
- Google Docs/shortcuts пропускаются с предупреждением и не превращаются в удаления.
- Локальная установка файла использует атомарную замену, а не API перемещения, которое может отвергать существующий файл.
- Ошибки доступны на экране и в истории; план не закрывается при неудачном выполнении, доступна перепроверка.
- Добавлены DOM-интеграционные тесты полного цикла и транспортные регрессии.
